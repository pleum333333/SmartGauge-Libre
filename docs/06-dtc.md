# 06 · โค้ดความผิดพลาด (DTC)

โค้ดอยู่ใน [`dtc.h`](../OBD_Dashboard/dtc.h) (ถอดรหัส + คำอธิบาย) และ `Elm327Ble::readDtcs()` ใน [`elm327_ble.h`](../OBD_Dashboard/elm327_ble.h)

## อ่านอะไรบ้าง

| คำสั่ง | ได้อะไร |
|---|---|
| `0101` | ไบต์ A: บิต 7 = ไฟ Check Engine (MIL) ติด, บิต 0–6 = จำนวนโค้ดที่ยืนยันแล้ว |
| `03` | โค้ดที่ **บันทึกแล้ว (stored / confirmed)** → ขึ้นชิปสีแดง `STORED` |
| `07` | โค้ด **รอยืนยัน (pending)** — เจอครั้งเดียว ยังไม่พอให้ไฟโชว์ → ชิปสีเหลือง `PENDING` |

อ่านตอนเปิดหน้า DTC, ตอนกด RESCAN และอ่านครั้งเดียวตอนต่อรถสำเร็จ (เพื่อให้ไฟเตือนเช็คเอนจิ้นบนหน้าปัดถูกต้อง)

## รูปแบบโค้ด

2 ไบต์ต่อโค้ด `A B`:

```
A บิต 7-6 : ตัวอักษร   00=P (เครื่อง/เกียร์) 01=C (แชสซี) 10=B (ตัวถัง) 11=U (เครือข่าย)
A บิต 5-4 : หลักแรก    0 = มาตรฐาน SAE, 1 = เฉพาะผู้ผลิต (2,3 ขึ้นกับตัวอักษร)
A บิต 3-0 : หลักที่สอง
B         : สองหลักสุดท้าย (hex)
ตัวอย่าง 01 33 → P0133
```

## ความต่างของรูปแบบคำตอบ (จุดที่ทำพังกันบ่อย)

**CAN (รถส่วนใหญ่หลังปี 2008):** หลังไบต์ `43` มี **จำนวนโค้ด** นำหน้า

```
43 02 01 33 02 44        → 2 โค้ด: P0133, P0244
```

ถ้าโค้ดเยอะเกิน 1 เฟรม ELM จะแบ่งเป็นหลายบรรทัด ขึ้นต้นด้วยความยาวรวมแล้วตามด้วย `0:`, `1:` …

```
00A
0:43040133024401
1:71010500000000
```

**ISO 9141 / KWP2000 / J1850 (รถเก่า):** ไม่มีจำนวนโค้ด ส่ง 3 โค้ดต่อบรรทัด เติม `0000` ถ้าไม่ครบ และอาจมีหลายบรรทัด

```
43 01 33 00 00 00 00     → P0133
```

`parseDtcResponse()` จัดการทั้งสองแบบ โดยดูจาก `isCan` ที่ได้จาก `ATDPN` และกรอง `0000` กับโค้ดซ้ำออก

## คำอธิบายโค้ด

`dtcDescription()` มีตารางโค้ด P0 ที่เจอบ่อย ~70 ตัว (MAF, O2, misfire, แคต, EVAP, คอยล์ ฯลฯ) เป็นภาษาอังกฤษ
- ถ้าเป็นโค้ด P0 ที่ไม่มีในตาราง → `Generic code`
- ถ้าเป็นโค้ดเฉพาะผู้ผลิต (P1xxx ฯลฯ) → `Manufacturer-specific`

**แผนต่อไป:** เก็บฐานข้อมูลโค้ดเต็ม (หลายพันตัว + ภาษาไทย) ไว้ใน **microSD** เป็นไฟล์ CSV แล้วค้นจากการ์ดแทน — ประหยัด flash และให้ชุมชนช่วยแปลได้

## ทำไมยังไม่มีปุ่มลบโค้ด (mode 04)

ตั้งใจไม่ใส่ เพราะ `04` ไม่ได้ลบแค่โค้ด:
- ลบ freeze frame (ข้อมูลสภาพเครื่องตอนเกิดปัญหา) ที่ช่างใช้วิเคราะห์
- รีเซ็ต readiness monitors → รถอาจไม่ผ่านตรวจสภาพจนกว่าจะขับวนครบรอบ
- โค้ดจะกลับมาอีกถ้ายังไม่ได้แก้ต้นเหตุ

ถ้าจะใส่ ควรเป็นปุ่มที่ต้อง **กดค้าง 3 วินาที + หน้ายืนยัน** และอ่าน freeze frame (mode 02) เก็บลง SD ก่อนลบ
