# 10 · ไลเซนส์และเครดิต (Licensing)

> **นี่ไม่ใช่คำแนะนำทางกฎหมาย** เป็นการสรุปจากแหล่งข้อมูลต้นทาง (ลิงก์ท้ายเอกสาร)
> ถ้าจะใช้ดำเนินคดีกับคนขายจริง ควรปรึกษาทนายด้านทรัพย์สินทางปัญญาในไทย

## ✅ ที่เลือกใช้: CC BY-NC-SA 4.0 (ตัดสินใจ 17 ต.ค. 2026)

ทั้งโค้ด เอกสาร และรูป ใช้ **CC BY-NC-SA 4.0** — ไฟล์ [`LICENSE`](../LICENSE) เป็นข้อความเต็มจาก creativecommons.org ไม่ได้แก้
เงื่อนไขเพิ่มที่ไม่ใช่ไลเซนส์ (คำขอให้เปิดซอร์ส / ส่ง PR กลับ) อยู่ใน [`CONTRIBUTING.md`](../CONTRIBUTING.md)
ข้อความเครดิตที่ต้องคงไว้อยู่ใน [`NOTICE`](../NOTICE) · เครดิตบนหน้าจอตอนบูตมาจาก `OBD_Dashboard/project.h`

ทางเลือกอื่นที่พิจารณาแล้ว (Parity + Prosperity, BSL 1.1 → GPL, PolyForm NC, Peer Production, FSL, Sustainable Use, Elastic 2.0)
ไม่มีตัวไหนรวม "ห้ามขาย + บังคับเปิดซอร์ส" ได้ครบ — CC BY-NC-SA ตรงเป้า "ห้ามขาย" ที่สุด

## เป้าหมายของเจ้าของโปรเจกต์

1. ใครเอาไปใช้/แก้ ต้อง **ให้เครดิต** ต้นทาง ("code written by …" + ลิงก์ repo)
2. **ห้ามใช้เชิงพาณิชย์** — หยุดคนเอาไปสั่ง AI แต่งนิดหน่อยแล้วขายเป็นสมาร์ทเกจ
3. ใครแก้แล้วเผยแพร่ ต้อง **เปิดเผยซอร์สด้วยเงื่อนไขเดียวกัน** เพื่อให้เอาฟีเจอร์ดี ๆ กลับมารวมใน repo หลักได้
4. จริงจังและบังคับใช้ได้มากที่สุดเท่าที่ทำได้

## ข้อเท็จจริงที่ต้องรู้ก่อน

- **ไลเซนส์ที่ "ห้ามขาย" จะไม่ถูกเรียกว่า "open source" ตามนิยาม OSI** (ข้อ 6: ห้ามกีดกันการใช้งานในสาขาใด ๆ รวมถึงธุรกิจ)
  คำที่ถูกต้องคือ **source-available** (เปิดซอร์ส แต่มีเงื่อนไข) — ควรเขียนใน README ให้ตรงไปตรงมา
- **GPL / AGPL / MPL ห้ามขายไม่ได้** — GPLv3 ข้อ 10 ห้ามเพิ่มข้อจำกัด และข้อ 7 ให้ผู้รับตัดข้อจำกัดที่เพิ่มเข้ามาทิ้งได้
  แต่ GPL บังคับว่าใครขายต้องแจกซอร์สเต็มให้ผู้ซื้อ ซึ่งทำลายธุรกิจ "เฟิร์มแวร์ลับ" ได้ในทางปฏิบัติ
- **ไม่มีไลเซนส์กระแสหลักตัวไหนบังคับให้เปิดเผยการแก้ไขที่เก็บไว้ใช้เอง** — บังคับได้เฉพาะตอน "เผยแพร่/แจกจ่าย"
  (RPL-1.5 กับ Open Watcom บังคับถึงการใช้งานภายใน แต่ทั้งสองยอมให้ขาย จึงไม่ตรงเป้า)
- **ไม่มีไลเซนส์ไหนบังคับให้คนส่งโค้ดกลับมาที่ repo เรา** ทำได้แค่บังคับให้เปิดเผย แล้วเราไปดึงมารวมเอง

## ทางเลือกที่แนะนำ

### ทางเลือก A — CC BY-NC-SA 4.0 ทั้งโปรเจกต์ (ตรงเป้าที่สุด)

- เป็นไลเซนส์ตัวเดียวที่รู้จักกันแพร่หลายและครอบคลุม **เครดิต + ห้ามขาย + ต่อยอดต้องใช้เงื่อนไขเดิม**
- โปรเจกต์สายเดียวกันในไทยและต่างประเทศใช้แนวนี้ (CC BY-NC, PolyForm NC, "MIT No Commercial")
- ข้อเสีย:
  - Creative Commons เองแนะนำว่าไม่ควรใช้กับซอฟต์แวร์ (ไม่มีข้อบังคับเรื่องซอร์สโค้ด ไม่มีเรื่องสิทธิบัตร)
  - คนที่แจกแค่ไฟล์ `.bin` อาจอ้างได้ว่าไม่ผิด — ต้องเขียนใน README/CONTRIBUTING ว่า "ขอให้เผยแพร่เป็นซอร์ส" (เป็นคำขอ ไม่ใช่ข้อบังคับ)
  - **ห้ามแก้ข้อความไลเซนส์ CC เอง** ไม่งั้นจะกลายเป็นไลเซนส์ทำเองที่บังคับใช้ยาก

### ทางเลือก B — PolyForm Noncommercial (โค้ด) + CC BY-NC-SA (เอกสาร/รูป/PCB)

- ร่างโดยนักกฎหมายสำหรับซอฟต์แวร์โดยเฉพาะ มีระยะแก้ไขความผิด 32 วัน มีข้อคุ้มครองสิทธิบัตร
- แต่ **ไม่บังคับให้ต่อยอดแล้วต้องเปิด** — เป้าข้อ 3 จะพึ่งได้แค่ CLA + ธรรมเนียมชุมชน

### ทางเลือก C — GPL-3.0 + จดเครื่องหมายการค้าชื่อโปรเจกต์ (ถ้ายอมให้ขายได้)

- เป็น open source แท้ ชุมชนยอมรับมากที่สุด คนขายต้องแจกซอร์สให้ลูกค้าทุกครั้ง
- จดเครื่องหมายการค้าชื่อโปรเจกต์ → ห้ามคนอื่นขายโดยใช้ชื่อเรา
- เจ้าของขายไลเซนส์เชิงพาณิชย์แยกเองได้ (ต้องมี CLA)
- แต่ **ไม่ได้ห้ามขาย** — ขัดกับเป้าข้อ 2

## สิ่งที่ควรทำเพิ่ม ไม่ว่าเลือกแบบไหน

| สิ่งที่ทำ | ทำไม |
|---|---|
| ไฟล์ `LICENSE` (ข้อความเต็ม ไม่แก้) | ตัวไลเซนส์จริง |
| ไฟล์ `NOTICE` | ข้อความเครดิตที่ต้องคงไว้: "Original work: <ชื่อโปรเจกต์> by <เจ้าของ> — <ลิงก์>" |
| หัวไฟล์ทุกไฟล์ `// SPDX-License-Identifier: …` + `// Copyright (c) 2026 …` | ระบุชัดทุกไฟล์ |
| **เครดิตบนหน้าจอตอนบูต / หน้า About** | ถ้ามีคนลบออกแล้วเอาไปขาย จะเห็นชัดในคลิปรีวิวสินค้า → เป็นหลักฐาน |
| `THIRD_PARTY_LICENSES.txt` | ไลบรารีที่ใช้มีไลเซนส์ของตัวเอง (ด้านล่าง) ต้องแนบเมื่อแจกไฟล์ `.bin` |
| `CONTRIBUTING.md` + CLA (เช่น CLA Assistant) | ให้เจ้าของรวมโค้ดคนอื่นและปรับไลเซนส์ในอนาคตได้ |
| **จดแจ้งลิขสิทธิ์กับกรมทรัพย์สินทางปัญญา** | ไม่บังคับ ราคาถูก ได้หลักฐานวันที่ ช่วยตอนแจ้งลบสินค้าบน Shopee/Lazada/Facebook |
| **จดเครื่องหมายการค้าชื่อโปรเจกต์** (คลาส 9) | เครื่องมือที่แรงที่สุดในการลบประกาศขายที่ใช้ชื่อเรา — ไม่ขึ้นกับปัญหาลิขสิทธิ์โค้ด AI · ประมาณ 1,000 บาท/รายการ (ยื่น) + 600 บาท/รายการ (จดทะเบียน) ใช้เวลา 12–18 เดือน **(ตรวจอัตราล่าสุดกับกรมฯ)** |
| `TRADEMARKS.md` | fork ต้องเปลี่ยนชื่อ ห้ามใช้โลโก้ |

## ข้อจำกัดที่ต้องยอมรับ (พูดตรง ๆ)

1. **โค้ดที่ AI เขียนล้วน ๆ อาจไม่มีลิขสิทธิ์** — สำนักงานลิขสิทธิ์สหรัฐฯ (ม.ค. 2025) ระบุว่าการสั่ง prompt อย่างเดียวไม่พอ
   คุ้มครองได้เฉพาะส่วนที่มนุษย์สร้างสรรค์ (การเลือก การจัดวาง การแก้ไข) · ไทยยังไม่มีแนวทางชัด แต่กฎหมายนิยาม "ผู้สร้างสรรค์" ว่าเป็นบุคคล
   → ไลเซนส์บังคับได้เฉพาะส่วนที่มีลิขสิทธิ์
   **วิธีลดความเสี่ยง:** เขียน/แก้ส่วนหลักด้วยตัวเอง, เก็บประวัติ git, บันทึกการตัดสินใจออกแบบ (เอกสารชุดนี้), ดีไซน์หน้าจอ/เอกสาร/รูปเป็นงานของคนชัดเจน
2. **ลิขสิทธิ์คุ้มครอง "การแสดงออก" ไม่ใช่ "ไอเดีย"** — ใครสั่ง AI เขียนเกจ OBD ใหม่ทั้งหมดโดยไม่ลอกโค้ด ไม่ผิด
3. **การบังคับใช้มีต้นทุน** — แพลตฟอร์มตอบสนองเร็วที่สุดเมื่อมีใบจดทะเบียนเครื่องหมายการค้า/หลักฐานจดแจ้ง
   กฎหมายลิขสิทธิ์ไทย (ฉบับที่ 5 พ.ศ. 2565) มีระบบแจ้งลบ (notice-and-takedown) ส่งตรงถึงผู้ให้บริการได้โดยไม่ต้องมีคำสั่งศาล
   การละเมิดเพื่อการค้ามีโทษทางอาญา
4. **ไลเซนส์เข้มทำให้คนช่วยพัฒนาน้อยลง** — แลกกันกับเป้าข้อ 3
