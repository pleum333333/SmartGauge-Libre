# 05 · ค่าเซ็นเซอร์ (Mode 01 PIDs)

ตารางอยู่ใน [`obd_pids.h`](../OBD_Dashboard/obd_pids.h) เป็นอาร์เรย์ `PIDS[]` ตัวเดียว ทุกหน้าในจออ่านจากที่นี่

## โครงสร้างหนึ่งแถว

```cpp
{0x0E, "Ignition adv", "*BTDC", 1, 0, 0.5f, -64, 1, 5, 35},
//pid  label           unit    bytes sgn mul  add dec lo hi
```

| ช่อง | ความหมาย |
|---|---|
| `pid` | หมายเลข PID |
| `label` | ชื่อบนการ์ด (ยาวไม่เกิน ~13 ตัวอักษร ไม่งั้นล้นการ์ด) |
| `unit` | หน่วย — ขึ้นต้นด้วย `*` จะวาดวงกลมองศาจริง (`*C` → °C, `*BTDC` → °BTDC) เพราะฟอนต์ไม่มีสัญลักษณ์ ° |
| `bytes` | 1 = ใช้ A, 2 = ใช้ A·256+B |
| `sgn` | ตีความ 2 ไบต์เป็น int16 มีเครื่องหมาย |
| `mul`, `add` | **ค่า = raw × mul + add** |
| `dec` | ทศนิยมที่แสดง (ค่า ≥ 1000 ไม่โชว์ทศนิยม) |
| `lo`, `hi` | ช่วงค่าปกติ — ใช้สร้างค่าปลอมในโหมด demo และความยาวแถบระดับใต้การ์ด |

ทุก PID ที่เป็น "ตัวเลขเดียว" ใน SAE J1979 ถอดได้ด้วยสูตรเชิงเส้นนี้หมด เลยไม่ต้องเขียนฟังก์ชันแยกทีละตัว

## ตัวอย่างสูตร

| PID | ค่า | สูตรมาตรฐาน | ใส่ในตาราง |
|---|---|---|---|
| 0C | รอบเครื่อง | (256A+B)/4 rpm | bytes 2, mul 0.25 |
| 0D | ความเร็ว | A km/h | mul 1 |
| 05 | อุณหภูมิน้ำ | A−40 °C | add −40 |
| 0E | **องศาจุดระเบิด** | A/2 − 64 °ก่อน TDC | mul 0.5, add −64 |
| 06–09 | fuel trim | (A−128)·100/128 % | mul 100/128, add −100 |
| 10 | MAF | (256A+B)/100 g/s | mul 0.01 |
| 14–1B | แรงดัน O2 | A/200 V | mul 0.005 |
| 24–2B, 34–3B, 44 | lambda | (256A+B)·2/65536 | mul 2/65536 |
| 3C–3F | อุณหภูมิแคต | (256A+B)/10 − 40 °C | mul 0.1, add −40 |
| 42 | แรงดันกล่อง ECU | (256A+B)/1000 V | mul 0.001 |
| 5D | จังหวะฉีด | (256A+B)/128 − 210 ° | |
| 5E | อัตราสิ้นเปลือง | (256A+B)/20 L/h | mul 0.05 |
| 61, 62 | แรงบิด | A − 125 % | add −125 |

### องศาการจุดระเบิด (PID 0x0E) คืออะไร

- เป็นค่าที่ ECU **สั่ง** จุดระเบิด วัดเป็นองศาเพลาข้อเหวี่ยง **ก่อนศูนย์ตายบน (BTDC)** ของสูบ 1
- เป็นค่ารวม ไม่ใช่ค่าแยกรายสูบ และไม่ใช่ค่าที่วัดจากไทม์มิ่งไลท์จริง
- ค่าที่ ECU ถอยไฟเพราะเครื่องน็อค จะเห็นเป็นตัวเลขที่ลดลงตรงนี้
- รถดีเซลส่วนใหญ่ไม่รองรับ PID นี้ (ไม่มีหัวเทียน) — ดู PID 5D จังหวะฉีดแทน

## เพิ่ม PID ใหม่

1. เพิ่มแถวใน `PIDS[]` (ตำแหน่งในอาร์เรย์ = ลำดับบนหน้ากริด)
2. ถ้าเป็นค่าที่ต้องเตือนสี ใส่ใน `pidColor()` และถ้าต้องการแถบสีหมวด ใส่ใน `pidAccent()` ใน `ui.h`
3. ไม่ต้องแก้อะไรอีก — PID ที่รถไม่รองรับจะถูกซ่อนเอง

ข้อจำกัด: ระบบ bitmask รองรับ PID ถึง 0x80 ถ้าจะเกินต้องขยาย `pidMask[]` ใน `elm327_ble.h`

## สีเตือน (`pidColor`)

| ค่า | เงื่อนไข |
|---|---|
| อุณหภูมิน้ำ | > 105 °C แดง, < 60 °C ฟ้า |
| น้ำมันเครื่อง | > 130 °C แดง |
| แบต | < 12.0 V ส้ม, > 14.8 V แดง, ปกติเขียว |
| น้ำมันเชื้อเพลิง | < 15 % แดง |
| fuel trim | เกิน ±10 % ส้ม |

ตัวเลขเหล่านี้เป็นค่าทั่วไป **ไม่ใช่สเปกของรถทุกคัน** ปรับให้เหมาะกับรถของคุณได้

## แหล่งอ้างอิง

- SAE J1979 / ISO 15031-5 (มาตรฐานตัวจริง เสียเงิน)
