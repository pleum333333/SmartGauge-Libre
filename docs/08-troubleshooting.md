# 08 · แก้ปัญหา (Troubleshooting)

| อาการ | สาเหตุที่เป็นไปได้ | วิธีแก้ |
|---|---|---|
| จอกระพริบ รีบูตวน COM port หาย ๆ โผล่ ๆ | ไฟไม่พอ (`rst:0x1 POWERON` ใน log) | ลด `BACKLIGHT`, ใช้พอร์ต USB/ที่ชาร์จที่จ่ายได้ ≥ 2A, เปลี่ยนสาย — [01-hardware.md](01-hardware.md) |
| Windows ไม่เห็นบอร์ดเลย (ไม่มี CH340) | สายชาร์จอย่างเดียว / พอร์ตเสีย / ไม่มีไดรเวอร์ CH340 | เปลี่ยนสายที่รับส่งข้อมูลได้, ลงไดรเวอร์ CH34x |
| จอดำแต่ Serial ทำงาน | ไม่ได้เลือก `PSRAM=opi` | ดู [02-build-and-flash.md](02-build-and-flash.md) |
| สีเพี้ยน / ภาพเลื่อน | timing จอไม่ตรงล็อต | ลอง `freq_write` 8–12 MHz, เช็ค porch ใน `board.h` |
| แตะจอไม่ติด | รุ่น R (resistive) หรือ address GT911 ต่าง | ดู log `I2C scan` จากเฟิร์มแวร์ทดสอบ |
| `Searching for OBD adapter...` ไม่จบ | dongle เป็น Bluetooth Classic / ชื่อไม่เข้าเงื่อนไข / dongle ไม่มีไฟ | เช็คใน nRF Connect, ตั้ง `OBD_DEVICE_NAME`, ดู log รายชื่ออุปกรณ์ |
| `no notify+write characteristic pair found` | dongle ใช้โครง GATT แปลก | ส่ง log ชื่อ service/characteristic มาที่ Issue |
| `No ECU reply - ignition ON?` | ยังไม่เปิดสวิตช์กุญแจ / รถไม่รองรับ OBD-II / ปลั๊กหลวม | เปิด ON (ติดเครื่องดีที่สุด) รอสักครู่ ระบบลองซ้ำทุก 3 วิ |
| ค่าบางตัวเป็น `--` ตลอด | รถไม่รองรับ PID นั้น หรือ ECU ตอบ `NO DATA` | ปกติ — หน้ากริดจะซ่อน PID ที่รถไม่รองรับหลังต่อสำเร็จ |
| ค่าอัปเดตช้า | ELM327 ตัวก๊อปตอบช้า | หน้าที่มีค่าน้อยกว่าจะอัปเดตเร็วกว่า; ดู roadmap เรื่องรวม PID |
| แตะเปลี่ยนหน้าช้าตอนยังไม่ต่อรถ | (เวอร์ชันเก่า) สแกน BLE บล็อกลูป | เวอร์ชันปัจจุบันย้าย OBD ไปคอร์ 0 แล้ว ไม่ควรเกิด |

## เก็บ log ไปแจ้งปัญหา

1. เปิด Serial Monitor 115200
2. กด RST บนบอร์ด
3. คัดลอกตั้งแต่ `== OBD Dashboard ==` จนถึงจุดที่มีปัญหา
4. **ลบ MAC address ของอุปกรณ์อื่น ๆ ที่ไม่เกี่ยวข้องออกก่อนโพสต์**
5. บอกรุ่นรถ ปี เครื่องยนต์ และยี่ห้อ/รุ่น dongle
