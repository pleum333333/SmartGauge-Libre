# 11 · รถที่รองรับ: OBD-II คืออะไร ใช้กับรถทุกคัน / มอเตอร์ไซค์ได้ไหม

## OBD-II = มาตรฐานกลาง (สำหรับรถยนต์)

OBD-II เป็นมาตรฐานบังคับเพื่อตรวจไอเสีย เริ่มที่สหรัฐฯ (ปี 1996) ยุโรปเรียก EOBD (เบนซิน 2001, ดีเซล 2004)
รถยนต์ที่ขายในไทยรุ่นใหม่ ๆ ส่วนใหญ่มีช่อง OBD-II ใต้คอนโซลฝั่งคนขับ
(ปีที่เริ่มมีในไทยต่างกันตามยี่ห้อ/รุ่น — **เช็ครถคันจริงดีที่สุด** ว่ามีปลั๊ก 16 ขารูปตัว D หรือไม่)

สิ่งที่ **เหมือนกันทุกคัน**:

| ส่วน | มาตรฐาน |
|---|---|
| ปลั๊ก | SAE J1962 16 ขา (ขา 16 = ไฟ 12V, ขา 4/5 = กราวด์) |
| โปรโตคอลสาย (เลือก 1 ใน 5) | CAN (ISO 15765-4) ← รถเกือบทุกคันหลังปี 2008, KWP2000 (ISO 14230), ISO 9141-2, J1850 PWM/VPW (รถอเมริกันเก่า) |
| คำสั่งอ่านค่า | SAE J1979 mode 01 (ค่าสด), 02 (freeze frame), 03/07 (โค้ด), 04 (ลบโค้ด), 09 (VIN) |
| รหัสโค้ด | P0xxx, C0xxx, B0xxx, U0xxx มีความหมายเดียวกันทุกยี่ห้อ |

**ELM327 เลือกโปรโตคอลสายให้เองอัตโนมัติ** (`ATSP0`) → เฟิร์มแวร์นี้ต่อกับรถยนต์ OBD-II ได้ทุกยี่ห้อโดยไม่ต้องแก้โค้ด

สิ่งที่ **ไม่เหมือนกันแต่ละคัน**:

- **รถแต่ละคันรองรับ PID ไม่ครบเท่ากัน** — กฎหมายบังคับเฉพาะค่าที่เกี่ยวกับไอเสีย
  โค้ดเราถามรถก่อน (`0100`, `0120` …) แล้วซ่อนค่าที่รถไม่มีให้อัตโนมัติ
- **ค่าเฉพาะยี่ห้อ** (อุณหภูมิน้ำมันเกียร์, เขม่า DPF, EGT บางรุ่น, ตำแหน่งเกียร์, ระดับน้ำมันจริง ฯลฯ) ใช้ mode 21/22 ที่แต่ละยี่ห้อกำหนดเอง
  ต้องทำ "โปรไฟล์รถ" แยกรุ่น (ดู [09-roadmap.md](09-roadmap.md#เฉพาะกระบะดีเซล-ตลาดไทย-))
- **โค้ดเฉพาะผู้ผลิต** (P1xxx, P2xxx บางช่วง, B/C/U อื่น ๆ) ความหมายต่างกันตามยี่ห้อ

### สรุปรถยนต์

| | รองรับ |
|---|---|
| รถยนต์/กระบะที่มีปลั๊ก OBD-II 16 ขา | ✅ ค่ามาตรฐาน + โค้ดมาตรฐาน |
| ค่าพิเศษเฉพาะยี่ห้อ (ATF, DPF …) | ⏳ ต้องเพิ่มโปรไฟล์รถ |
| รถเก่ามาก (ก่อนมี OBD-II / ปลั๊กแบบเฉพาะยี่ห้อ) | ❌ |
| รถไฟฟ้า (EV) | ⚠️ ส่วนใหญ่ไม่บังคับ OBD ไอเสีย ค่าแบตใช้คำสั่งเฉพาะยี่ห้อ |

## มอเตอร์ไซค์ — ไม่มีมาตรฐานกลางแบบรถยนต์

มอเตอร์ไซค์ส่วนใหญ่ **ไม่ใช่ OBD-II** แม้จะมีช่องวิเคราะห์:

- ปลั๊กเป็นแบบของแต่ละยี่ห้อ (3, 4, 6 ขา) ไม่ใช่ 16 ขา
- ส่วนใหญ่สื่อสารทางสาย **K-line** (ระดับไฟฟ้าเดียวกับ ISO 9141/14230) แต่ **ข้อความข้างในเป็นแบบเฉพาะยี่ห้อ**
  เช่น Honda (PGM-FI), Yamaha, Kawasaki (KDS), Suzuki (SDS) — ใช้คำสั่ง mode 01 มาตรฐานไม่ได้
- มอเตอร์ไซค์รุ่นใหม่ในยุโรปที่ผ่านมาตรฐาน Euro 5 ต้องมี OBD และบางรุ่นตอบคำสั่งมาตรฐานได้ (ต้องใช้สายแปลงปลั๊ก)
  **ยังไม่ได้ตรวจสอบว่ารุ่นที่ขายในไทยทำแบบนั้นได้แค่ไหน**

### ถ้าจะรองรับมอเตอร์ไซค์ในอนาคต

1. ฮาร์ดแวร์: ต่อสาย K-line ตรงกับ ESP32 ผ่านชิปแปลงระดับไฟ (เช่น L9637D / MC33660 / ทรานซิสเตอร์ + ตัวต้านทาน) — ไม่ต้องผ่าน ELM327
2. ซอฟต์แวร์: เขียนโปรโตคอลแยกยี่ห้อ (เริ่มจาก Honda PGM-FI ที่มีชุมชนแกะไว้เยอะที่สุด)
3. ทำเป็นโมดูล `vehicle/<brand>.h` แยกจากโค้ด OBD-II รถยนต์

ไม่มีใครรับประกันได้ว่ารองรับ "มอเตอร์ไซค์ทุกรุ่น" — ต้องทดสอบทีละยี่ห้อทีละรุ่น
